# ORBITA BAGS

Sitio de ORBITA BAGS — bolsas courier compostables para ecommerce en Chile. Frontend en React + Vite, conectado a Shopify vía Storefront API (canal Headless).

## Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Desarrollo local

Requisitos: Node.js y npm ([instalar con nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
# Clonar el repo
git clone <YOUR_GIT_URL>

# Entrar a la carpeta del proyecto
cd orbit-ship-eco

# Instalar dependencias
npm i

# Levantar el servidor de desarrollo
npm run dev
```

## Build y deploy

```sh
npm run build
```

El sitio se despliega en Cloudflare Pages.
